Manga Reader

Présentation

Manga Reader est une application mobile de lecture de mangas. Elle a été réalisée durant la journée du code avec le framework Flutter.

  • Nom du projet : manga_reader
  • Version : 1.0.0
  • Source des données : API MangaDex
  • Plateformes : Android, iOS, Windows, Linux, macOS, Web

Technologies

  • Flutter et Dart : interface multiplateforme
  • Dio : requêtes vers l'API MangaDex
  • Riverpod : gestion de l'état de l'application
  • go_router : navigation entre les écrans
  • Supabase : base de données dans le cloud
  • SQLite et SharedPreferences : stockage local
  • cached_network_image et photo_view : images en cache et zoom
  • flutter_local_notifications : notifications locales
